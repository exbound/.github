# .github

Organization-wide community health files and policy for
[Exbound](https://github.com/exbound). Files here apply as defaults across every
Exbound repository that does not provide its own.

- [`profile/README.md`](profile/README.md) — the public organization profile.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute, and the evidence and
  compatibility-claim standards.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
- [`SECURITY.md`](SECURITY.md) — vulnerability reporting and the lawful-use
  scope boundary.
- [`SUPPORT.md`](SUPPORT.md), [`GOVERNANCE.md`](GOVERNANCE.md)
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) and
  [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) —
  default issue and pull-request templates.
- [`branding/`](branding) — the visual-identity tokens (draft).

A repository overrides any of these by providing its own copy.
