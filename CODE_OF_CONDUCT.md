# Code of Conduct

Exbound is a technical community that depends on people from very different
backgrounds — scientists, engineers, developers, reverse engineers — doing
careful work together.

## Expected behavior

- Engage with the technical substance. Critique claims and code, not people.
- Back assertions with evidence. "I reproduced X with command Y" moves the work
  forward; unsupported certainty does not.
- Assume competence and good faith. Contributors come from different fields and
  will know different things.
- Respect provenance and the law: contribute only lawfully held material, and
  don't pressure others to cross the scope boundary in
  [CONTRIBUTING](CONTRIBUTING.md).

## Unacceptable behavior

Harassment, personal attacks, discriminatory or demeaning language, deliberate
intimidation, publishing others' private information, and sustained disruption.

## Scope

This applies in all Exbound spaces — repositories, issues, pull requests, and
discussions — and when representing Exbound elsewhere.

## Enforcement

Report conduct concerns privately to the maintainers (see
[SUPPORT](SUPPORT.md) for the contact). Reports are handled confidentially.
Maintainers may remove content and warn or remove contributors for behavior that
violates this document.

This Code of Conduct adapts the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
