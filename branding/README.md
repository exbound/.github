# Branding

The Exbound visual identity reads as a modern scientific-engineering
publication, not a startup landing page. These are the working tokens the
website and social previews build on.

**The mark and favicon still need visual review — treat the SVG here as a
draft, not a finished logo.**

## Palette (draft)

| Token       | Role                          | Hex       |
|-------------|-------------------------------|-----------|
| Graphite    | Primary text / dark surfaces  | `#22262b` |
| Warm white  | Background                    | `#f7f4ee` |
| Signal lime | Accent / calls to action      | `#c3e600` |
| Steel blue  | Links / secondary accent      | `#35618e` |

Hex values are a starting point for review, not final.

## Typography

- Large editorial headings (a strong display face).
- A readable humanist sans for body text.
- Monospace for technical metadata — versions, hashes, capability codes.

## Usage

- Minimal iconography; restrained scientific illustration over decorative
  graphics.
- Never use a vendor's logo, product name, or branding to describe a target.
  Describe by compatibility.

Files here (`exbound-wordmark.svg`, and a favicon to come) are drafts pending
the founder's visual review.
